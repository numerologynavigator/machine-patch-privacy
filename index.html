Data practices in this version

VersionCode 1 stores game progress on the device. It does not send that progress to Navrang Labs or to anyone else. It does not collect or share personal information off the device.

This version has no account or sign-in, and it does not include an analytics SDK. It has no chat, no in-app purchases, and no location sharing.

Game progress stays on the device

Progress is stored only in the app’s local preferences, under the name machine_patch.

Android backup is turned off for the app, and the app’s data-extraction rules exclude preferences. Progress in machine_patch is not included in Android backup.

Clearing the app’s storage, or uninstalling the app, removes that local progress from the device. There is no account and no separate server copy of progress in this version. This policy does not state a retention period, and it does not describe a backup service or a developer-side deletion process for game progress.

Advertising libraries in this version

Current build. Google Mobile Ads and the User Messaging Platform are packaged in versionCode 1 and are inactive. This section describes that current build. It does not say that every future build will omit advertising data.

The app package includes the Google Mobile Ads SDK version 25.5.0 and the Google User Messaging Platform (UMP) SDK version 4.0.0. In versionCode 1, versionName 0.1.0, those libraries do not run their collection path:

  • LIVE_ADS is false.
  • The release build sets ADS_LIVE_GATE to false, so ad configuration is off.
  • The ads startup path returns before any consent update and before MobileAds.initialize.
  • The merged manifest sets DELAY_APP_MEASUREMENT_INIT to true, and the MobileAdsInitProvider component is removed.
  • This version does not request ads, does not read an advertising identifier, and does not transmit game progress.

The install manifest includes com.google.android.gms.permission.AD_ID and android.permission.ACCESS_ADSERVICES_AD_ID because the advertising SDK is packaged. This version does not use those permissions and does not read an advertising ID.

A later build that turns advertising on

The following is a condition for a future build. It is not a description of collection by versionCode 1, versionName 0.1.0.

Before any build with advertising enabled is offered, this policy, the in-app consent flow, and the Google Play data disclosures have to be updated. A build with advertising enabled may collect and share identifiers, IP address, ad interactions, and diagnostics with Google. VersionCode 1 does not do that.

Intended age

Machine Patch is intended for people aged 13 and older. That is the developer’s intended audience for this app.

A store content rating such as IARC General, Everyone, or PEGI 3 is a different label. It is not this policy’s age designation, and it is not an age check inside the app.

This version does not ask for a date of birth or other age information. It has no age gate and no parental controls or other safeguards that would limit use by a younger person.

Controls on the device

Game progress for this version is local. To remove it from a device:

  • Open Android Settings, then Apps, then Machine Patch, then Storage, and clear storage. Some devices label this control “Clear data”.
  • Or uninstall Machine Patch.

Clearing storage removes the app’s local data on that device, including machine_patch preferences. Uninstalling removes the app and that local data from the device.

Security

Progress is kept in ordinary private app storage on the device. This policy does not guarantee that the device, the app, or this website will prevent loss, disclosure, or unauthorized access. Someone who controls the device may be able to reach data stored on it.
